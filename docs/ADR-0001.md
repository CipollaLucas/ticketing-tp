# ADR-0001 — Bootstrap y límites de alcance
Estado: Propuesta, 2026-11-23.

## Contexto
Se requiere una plataforma de ticketing con microservicios en etapas. Bootstrap no demuestra servicios independientes.

## Decisión
Empezar por un monorepo con API y frontend mínimos, manteniendo documentación OpenSpec de los futuros límites de servicio. En el change de arquitectura se definirá despliegue independiente y propiedad de datos de Identity, Events y Ticketing.

## Consecuencias
Entrega temprana y testeable; deuda explícita: microservicios, Alembic operativo, API dominio, inventario concurrente y despliegue.
