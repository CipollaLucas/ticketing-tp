## Revisión y correcciones
Una revisión independiente de solo lectura detectó carrera entre administradores y falta de pruebas efectivas de restricciones de migración. Se corrigieron ambos puntos. Regresión de concurrencia sobre PostgreSQL: al retirar temporalmente la corrección, ambas requests devolvieron 200 y el test falló; con locks ordenados y relectura del rol, devuelve un 200 y un 403 y conserva un administrador. Suite completa verde después de corregir.

La primera prueba de imagen detectó que el Dockerfile no copiaba Alembic (dos tests de migración fallaron). Se agregaron alembic.ini y alembic/ a la imagen y se reconstruyó: suite completa verde. Un falso positivo de test de password usaba la palabra `short`, que coincidía con el tipo de error `too_short`; se reemplazó por una contraseña centinela inequívoca. No fue una filtración del servidor.
